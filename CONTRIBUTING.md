# Contributing

Thanks for wanting to help. Job Finder is a one-person project and the code is all rights reserved (see [LICENSE](LICENSE)), so the most useful thing you can do is tell me what you see:

- **Bugs, wrong ads, wrong AI answers and ideas:** use the feedback links in the app's footer, or [open an issue](https://github.com/JMAWD/job-finder/issues/new). The app's links fill in the version, language and browser for you.
- **Security problems:** please follow [SECURITY.md](SECURITY.md) instead of opening an issue.

Please open an issue before writing any code. Because of the licence I can only take a pull request with written agreement first, and an issue is the place to talk that through.

Issues are public. Leave out your CV, your name and anything else personal.
